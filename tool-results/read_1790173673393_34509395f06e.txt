   148→   148→8.3 Recursive Rule for a Sequence
   149→   149→So far, we have used a formula in terms of n for the nth term as 
   150→   150→the explicit rule for a sequence. There is another way of writing 
   151→   151→the rule for a sequence. Consider the sequence 1, 4, 7, 10, 13, … . 
   152→   152→The nth term is tn = 3n – 2 (verify this for yourself). Note that each 
   153→   153→term is 3 more than its previous term. Thus, t2 = t1 + 3, t3 = t2 + 3, 
   154→   154→t4 = t3 + 3 and so on. In general, we can say tn = tn–1 + 3 for n ≥ 2. 
   155→   155→Or we can describe the sequence as t1 = 1, tn = tn–1 + 3, where n can take 
   156→   156→the values 2, 3, 4, …  This way of describing a sequence by relating 
   157→   157→terms to previous terms is known as a recursive rule or recursive 
   158→   158→formula. If you know earlier terms of the sequence, then you can 
   159→   159→find the next terms using the rule. Note that the earlier terms need 
   160→   160→to be known to us to use the recursive rule to find the next terms.
   161→   161→Example 3: Find the first four terms of the sequence given by the 
   162→   162→recursive rule
   163→   163→u1  = 1, un = 2un–1 + 3 for n ≥ 2. Is 133 a term of this sequence?
   164→   164→We successively insert the values of n as 2, 3, 4, etc., and compute the 
   165→   165→values of each term.
   166→   166→u2 = 2u1 + 3 = 2 × 1 + 3 = 5
   167→   167→u3 = 2u2 + 3 = 2 × 5 + 3 = 13
   168→   168→u4 = 2u3 + 3 = 2 × 13 + 3 = 29
   169→   169→Thus, the first four terms of the sequence are 1, 5, 13, 29. Calculating 
   170→   170→subsequent terms, we can check if 133 is a term of this sequence.
   171→   171→Example 4: Find the first four terms of the sequence given by the 
   172→   172→recursive rule s1 = 3, sn = sn–1 (sn–1 – 1) for n ≥ 2.
   173→   173→Substitute the values of n as 2, 3, 4, etc., and compute the values of 
   174→   174→each term as follows.
   175→   175→s2 = s1 (s1 – 1) = 3 × (3 – 1) = 3 × 2 = 6
   176→   176→s3 = s2 (s2 – 1) = 6 × (6 – 1) =  6 × 5 = 30
   177→   177→s4 = s3 (s3 – 1) = 30 × (30 – 1) = 30 × 29 = 870
   178→   178→179

   180→   180→Thus, the first four terms of the sequence are 3, 6, 30, 870.

   263→   263→difference is – 4.

   267→   267→tn = a + (n – 1) × d is an expression for the nth term of any arithmetic 
   268→   268→progression, for some fixed values of a and d.
