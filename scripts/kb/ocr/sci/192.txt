Prefixes, such as mono- (1), di- (2), tri- (3), tetra- (4), penta- (5), hexa- (6), etc.,
indicate the number of atoms. However, mono- is usually omitted for the first
element but is used for the second element. If a prefix ends with ‘o’ or ‘a’ and
the element starts with a vowel, drop the last vowel (for example, monoxide,
pentoxide). If the prefix ends with ‘’, keep it for pronunciation (for example,
dioxide, trioxide).

When hydrogen is the first element in the formula, no prefix is added
before hydrogen, irrespective of the number of its atoms. For example, HS
is named hydrogen sulfide, not dihydrogen sulfide.

A few binary compounds are known only by their common names.
For example, H,O, which would usually be named hydrogen monoxide,
is commonly known as water, Similarly, NH,, which is actually nitrogen
trihydride, is known as ammonia.
